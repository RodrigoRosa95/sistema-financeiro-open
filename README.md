# Sistema financeiro (versão aberta)
Backend Node/Express (porta 3004) com SQLite, bot de WhatsApp/Telegram, integração Pluggy/Mercado Pago, skill Alexa e comprovantes.
Os dois usuários padrão são `user1` (admin) e `user2`; ajuste nomes, senhas e ids pelo `.env` (veja `.env.exemplo`).
`npm install && node sistema-mobile-3004.js`. Licença MIT.
